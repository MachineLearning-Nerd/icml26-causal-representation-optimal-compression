# Branch audit

The source repository had one branch named master and no separate experiment branches. It is normalized to main for the ICML 2026 collection.

Current branch policy:

- main is the canonical documentation and verifier branch.
- No branch is presented as a causal-model or CausalEGM reproduction.
- New evidence should use a descriptive audit branch and record its paper version, command, inputs, outputs, and limitations before merging.

The old master name is retained only as a history fact; it is not a current remote branch.
